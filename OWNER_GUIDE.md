# Owner Guide – LALA RESTAURANT Website

Your website has two parts:
- **Customer website:** `https://YOUR-WEBSITE`
- **Admin panel (private):** `https://YOUR-WEBSITE/admin.html` – log in with your admin password.

Bookmark the admin page on your phone. Never share your password.

## Everyday tasks

**See new bookings and orders**
Admin → *Bookings*. New requests show as **Pending**. Tap the phone number to call the customer.
Change the status (Confirmed / Completed / Cancelled) using the drop-down on that row.
You also get a message on Telegram/WhatsApp/email each time someone submits the form.

**Change a dish or price**
Admin → *Menu* → choose the dish → edit → **Save Dish**. It updates on the website instantly.

**Add a new dish**
Admin → *Menu* → **Add Dish**. Fill in name, price, category, short description. For the photo, paste a
picture link that starts with `https://`. (Ask your developer if you want your own photos uploaded.)

**Remove a dish**
Admin → *Menu* → delete icon on that dish.

**Show "Today's Special" banner**
Admin → *Store Settings* → tick *Announcement*, type your message, **Save**.

**Mark the shop Closed for the day**
Admin → *Store Settings* → untick *Currently Open*, **Save**. Customers will see "Currently Closed".

**Change phone number, opening hours, address**
Admin → *Store Settings* → edit → **Save**.

**Download all bookings**
Admin → **Export CSV** (opens in Excel/Google Sheets). Do this once a week as a safety copy.

## If something goes wrong

| Problem | What to do |
|---|---|
| Can't log in | Check caps lock. After 5 wrong tries wait 5 minutes. Still stuck → contact your developer to reset the password. |
| Website not opening | Wait 2 minutes and refresh. If still down, contact your developer. |
| Not getting booking alerts | Check the admin panel – bookings are always saved there even if alerts fail. Tell your developer. |
| Menu change not visible | Refresh the customer page (pull down on phone). |

## Keep safe
- Use a long, unique admin password. Change it if a staff member who knew it leaves.
- Do not open the admin panel on shared/public computers.
- Keep the domain and hosting renewals in your own name and note the renewal dates.

## சுருக்க வழிகாட்டி (Tamil quick guide)

- **புதிய ஆர்டர்/முன்பதிவு பார்க்க:** Admin → *Bookings*. வாடிக்கையாளர் எண்ணை தொட்டால் நேரடியாக அழைக்கலாம்.
- **உணவு விலை மாற்ற:** Admin → *Menu* → உணவை தேர்வு செய்து மாற்றி **Save Dish** அழுத்தவும்.
- **புதிய உணவு சேர்க்க:** Admin → *Menu* → **Add Dish**.
- **இன்றைய சிறப்பு அறிவிப்பு:** Admin → *Store Settings* → Announcement எழுதி **Save**.
- **கடை மூடியிருந்தால்:** Admin → *Store Settings* → *Currently Open* தேர்வை நீக்கி **Save**.
- **பாஸ்வர்டை யாருடனும் பகிர வேண்டாம்.** வாரம் ஒருமுறை **Export CSV** மூலம் பதிவுகளை சேமித்து வைக்கவும்.
